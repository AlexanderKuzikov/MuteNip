## Открытые вопросы

| # | Приоритет | Описание |
|---|-----------|----------|
| 1 | low | Пути длиннее 260 символов могут не пережить вызов ffmpeg; файл падает в ошибку, пачка продолжается |
| 2 | low | Оценка экономии для VBR-аудио врёт; фактическая цифра появляется только после обработки |
| 3 | info | Нет перекодирования: потоки, которые нельзя скопировать, завершаются ошибкой. Это осознанно, см. ADR 002 |
| 4 | info | Удаление исходников без корзины. Защита — подтверждение и проверка результата, восстановления нет |
| 5 | info | UI без манифеста DPI; при масштабе 150% WebView2 отдаёт `devicePixelRatio = 1.5`, окно масштабируется системой |
| 6 | low | Клик по папке сразу запускает скан; на огромном дереве это может быть долго. Отмена есть в прогресс-строке |
| 7 | info | Смонтированные облачные диски видны как обычные буквы (на машине разработчика — 18 дисков), список длинный |
| 8 | low | Дерево навигации кэширует содержимое папок; новые папки видны после кнопки «обновить» или перезапуска |
| 9 | info | Автотестов на живой ffmpeg нет: интеграционные сценарии проверяются вручную через headless-API |

## Проверка

```powershell
go vet ./...
go test ./...

$env:MUTENIP_HEADLESS = "1"
$env:MUTENIP_PORT = "8899"
$env:MUTENIP_DATA = Join-Path $env:TEMP "mutenip-data"
.\mutenip.exe
curl.exe --noproxy "*" -s http://127.0.0.1:8899/api/fs/drives
```

`MUTENIP_DATA` обязателен для тестов: иначе конфиг и лог пишутся в реальный `%LOCALAPPDATA%\MuteNip`.
