# MuteNip — инструкции для AI-агентов

Desktop-утилита для Windows: удаляет аудиодорожку из локальных видео без перекодирования. Go + WebView2 + внешние ffmpeg/ffprobe.

## Команды

- build: `go build -ldflags="-s -w -H windowsgui" -o mutenip.exe .`
- test: `go test ./...`
- vet: `go vet ./...`
- headless: `$env:MUTENIP_HEADLESS="1"; $env:MUTENIP_PORT="8899"; $env:MUTENIP_DATA=Join-Path $env:TEMP "mutenip-data"; .\mutenip.exe`
- запросы к headless — только `curl.exe --noproxy "*"` (Invoke-RestMethod на loopback падает из-за прокси).
- regenerate icon resource: `rsrc -ico icon/mutenip.ico -o rsrc.syso`

## Структура

- `main.go` — WebView2, loopback-сервер, `MUTENIP_*`.
- `api.go` — HTTP-контракт: скан, обработка, статусы, открытие папки. Состояния защищены одним мьютексом.
- `fs.go` — диски и список папок для постоянной навигации (`/api/fs/drives`, `/api/fs/list`). Сетевые диски отсекаются.
- `winutil.go` — mutex одного экземпляра, иконка окна, проверка WebView2, конфиг, лог, MessageBox.
- `mute/` — ядро без UI:
  - `tools.go` — поиск ffmpeg/ffprobe: exe dir → ClipNip cache → PATH.
  - `probe.go` — ffprobe JSON, оценка размера аудио.
  - `scan.go` — обход папки, белый список расширений, пул проб.
  - `process.go` — ремукс, прогресс, проверка результата, копия `_na` / замена с удалением.
  - `run.go` — `CREATE_NO_WINDOW`, kill-tree, ограниченный буфер stderr.
- `web/` — UI (вшит через `embed`): постоянное дерево дисков, список файлов, выбор, прогресс.
- `icon/` — SVG-исходник и ICO; `rsrc.syso` — ресурс exe.

## Конвенции

- Только Windows x64. WebView2 Runtime — предпосылка, проверяется при старте.
- Бинарники ffmpeg/ffprobe не вшивать: PE внутри PE раздувает exe и даёт ложные срабатывания антивирусов. См. `docs/DECISIONS.md` ADR 001.
- Никакой сети: утилита работает только с локальными файлами и дисками.
- Перекодирования нет. Если stream copy не удался — ошибка по файлу, пачка продолжается.
- UI: обычный регистр текста, без капса; никаких внешних CDN и шрифтов.
- Коммиты — прямо в `main`, повелительное наклонение, ≤72 символа. После завершённой работы коммит и пуш в публичный `origin`.
- После работы обновить `docs/CONTEXT.md`; архитектурное решение — в `docs/DECISIONS.md`.

## Грабли (проверено)

1. **`exec.CommandContext` не убивает дочерние процессы на Windows.** Отмена — только `taskkill /PID <pid> /T /F` (`mute.KillTree`).
2. **`ffmpeg -progress` пишет `out_time_us` и `out_time_ms`, оба в микросекундах.** Не делить `out_time_ms` на 1000.
3. **`-map 0 -map -0:a` сохраняет субтитры, главы и вложения; `-c copy` не перекодирует.** Проверено на mkv с subrip.
4. **Удалять исходник можно только после ffprobe-проверки результата.** Порядок: temp → verify → rename original → rename temp → remove old. Менять порядок нельзя.
5. **Даже в режиме удаления нужен свободный объём на размер файла:** сначала пишется временная копия.
6. **Оценка экономии — `bit_rate × duration`; для VBR врёт.** Не выдавать её за точную; фактическая разница считается после ремукса.
7. **Тесты не должны писать в реальный `%LOCALAPPDATA%\MuteNip`.** Использовать `MUTENIP_DATA`.
8. **Не переиспользовать CSS-класс `.empty` для бейджей:** он задаёт стили пустого состояния (padding 30px). Для скрытых бейджей — `.badge.hidden`.
9. **Дерево навигации ленивое и кэшируется.** Новые папки видны после «обновить»; не делать рекурсивный обход диска при открытии.
10. **Клик по диску только раскрывает его; сканирование корня диска запрещено случайно.** Не менять без причины.
11. **DPI:** манифеста DPI нет; WebView2 отдаёт `devicePixelRatio` системы, окно масштабируется Windows. На 150% интерфейс может быть мягким.
12. **`rsrc.syso` закоммичен.** Сборка без него лишится иконки; после замены `.ico` перегенерировать.

## Не делать

- Не добавлять встраивание ffmpeg/ffprobe и сетевые загрузки компонентов.
- Не менять формулировки предупреждения об безвозвратном удалении без явной команды.
- Не перезаписывать существующий `name_na.ext`.
- Не пушить force и не делать hard reset без подтверждения.
